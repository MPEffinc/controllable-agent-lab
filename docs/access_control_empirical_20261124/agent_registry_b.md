## 즉시 반영할 경계·후속 확인

- **K09:** [논문 §5](https://arxiv.org/html/2605.26497v1#S5)는 같은 observation의 원천 오염, graph-builder 귀속 오류, multi-agent 경계, replan whitelist 내부 오용을 인정한다. 코드가 공개되기 전에는 구현 추적 또는 원저자 조건 재현으로 기록하지 않는다.
- **K11:** [논문 §VI](https://arxiv.org/html/2610.05640v1#S6)는 보장/평가를 계층적 tree agent-as-tool 및 CFI에 한정한다. DAG/비동기/공유 상태와 더 강한 정보 흐름 속성은 확장 과제다. [§V](https://arxiv.org/html/2610.05640v1#S5)는 MultiAgentDojo 97 정상 task·949 injected instances/model/configuration을 명시한다. zero ASR는 이 분모의 관측이다. README의 fake-client 테스트는 실제 Sequrity 서비스/모델 benchmark 재현이 아니다.
- **K12:** [논문 §4](https://arxiv.org/html/2510.17276v2#S4)는 **agent 간 전환**이 PEP라고 명시하고 black-box agent 내부 tool 호출은 관측 불가라고 한다. ControlValve가 내부 tool/effect를 직접 막았다는 식의 서술은 피해야 한다.
- **K13:** [README](https://github.com/eunomia-bpf/ActPlane#quickstart)는 `notify`/`kill`/`block`을 구별하고 실제 eBPF runtime에 권한을 요구한다. 무권한 policy compile 결과는 집행 증거가 아니다.
- **K15:** [README Trust and scope](https://github.com/zast-ai/continuity#trust-and-scope)는 신뢰된 issuer, verifier, key, 모든 보호 대상 finality sink를 TCB로 열거하며 외부 validator의 의미적 정확성·모든 실제 effect 경로·매개되지 않은 유해 텍스트는 증명하지 않는다고 한다.

## 조회 방법·미확인 항목

`git ls-remote <공식 저장소 URL> HEAD`로 위 5개 SHA를 조회했다. 같은 방법으로 확인한 원격 태그는 K13 `v0.0.9`까지, K14 `v0.1.9`까지였고, K10·K11·K15에는 태그가 조회되지 않았다. 이는 정렬 가능한 태그의 관측이며 해당 tag가 논문 평가판이라는 뜻이 아니다. 직접 clone/build/실행 전 소스 설치 스크립트·의존성·라이선스를 각 고정 commit에서 재확인해야 한다. 패키지 배포판/태그와 논문 실험 commit의 정확한 대응, K09·K12 비공개 코드 여부, K11 별도 AssetOpsBench 데이터 공개 여부는 `UNKNOWN`이다.
