# 문제·한계·대응 연구 비교표

기준일: **2026-11-23**. `P01–P15`는 한 논문이 아니라 **보호하려는 조건**에 부여한 ID다. Generation, Enforcement, Verification은 표의 읽기 순서이며 한 연구가 여러 문제를 다룰 수 있다. `A`는 저자 명시 한계, `B`는 원문 구현·평가 범위에서 확인한 제한, `C`는 이 조사의 추론, `D`는 논문이 보고한 실제 시험·반례다. `D`는 이 조사의 재실행 결과가 아니며 같은 위협 모델 밖으로 일반화하지 않는다. 모든 `대응 연구`의 화살표는 **문제에 대한 해결 경로**를 뜻하며 후속 인용·구현 상속을 뜻하지 않는다. 해당 관계가 실제 확장일 때만 `EXTENDS`라고 표시했다.

`현재 판정`은 행의 넓은 문제에 대한 문헌 판정이다. `PARTIALLY_RESOLVED`에는 이미 해결된 조건을, `UNVERIFIED`에는 아직 근거가 필요한 조건을 명시했다. 특정 구현의 실패와 접근통제 연구 전체의 미해결을 동일시하지 않는다. 논문 제목·저자·버전·학회·DOI의 검증 기록은 각 원문 및 함께 제공한 세 범주 조사 노트에 있다.

## 판정의 경계

- **확인된 해결:** P11의 *형식* 정책 검사, P02의 정확한 규칙 집합에 대한 무승인 확대 차단, P06의 적절한 OS/network 계층에서의 자원 매개 등은 이미 강한 해결 경로가 있다. 이들을 넓은 미해결 주장으로 재포장하지 않는다.
- **직접 관찰된 제한:** P03의 attacker-writable 위임 값, P08의 GitHub MCP reviewed-head 미결속과 Kafka 기존 요청, P10의 shared-HMAC origin 재작성, P12의 잘못된 verification target, P14의 residual consent, P15의 국소 허용/전체 정책 불일치는 각각 지정된 시험에서 `D`다. 서로 다른 위협 모델·논문 버전의 수치를 우열 비교하지 않는다.
- **아직 확정하지 않은 Need:** 승인 의미의 *정당한 근거*, 장기 맥락에서 *필수 결속 사실*, 다중 agent·provider에서 *완전한 effect 관측과 제어*는 공통 전제다. PAuth/PACT/ROPE/SPILLWAY, ASU/CTA/CONTINUITY/EffectBound, ActPlane/OpenShell, 전통적 capability·IFC·분산 시스템 기술을 같은 조건에서 반박하지 못한 채 `OPEN_WITH_EVIDENCE`로 올리지 않는다.
- **출처 접근 제한:** `LEASH: Zero-Trust Containment for AI Agent Swarms` [DOI 10.1145/3847352.3848103](https://doi.org/10.1145/3847352.3848103), `Ghost Approvals` [DOI 10.1145/3847352.3848101](https://doi.org/10.1145/3847352.3848101), `ContractGuard` [DOI 10.1145/3830454.3846789](https://doi.org/10.1145/3830454.3846789)은 본문 접근이 되지 않아 메타데이터나 저자 초록을 넘는 메커니즘 근거로 쓰지 않았다.
