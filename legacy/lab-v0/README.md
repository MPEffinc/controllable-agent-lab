# legacy/lab-v0: 직접 구축한 소형 환경 (S0~S2)

**위치: 결과의 근거로 쓰지 않는 학습·부품 시험용이다.** 이 폴더의 수치와 관찰은 논문·보고서의 근거가 아니며,
새 실험(SREGym 기반, 루트 README 참고)이 이 폴더의 코드를 부품으로 가져다 쓸 때의 원본이다.
정리 전 상태는 git 태그 `lab-v0` 로 복원할 수 있다(`git checkout lab-v0`).

## 무엇을 위한 환경이었나
연구 질문 "읽기 전용 도구가 거짓 정보를 주면, 쓰기 권한을 가진 에이전트가 허용 범위 안에서 해로운 행동을 하는가.
어떤 안전장치가 어디서 막는가"를 SQLite 하나짜리 가짜 세계로 줄여 돌려 보는 모형이다. 목적은 두 가지였다.
1. 에이전트 루프·권한 분리·게이트·판정기 같은 메커니즘을 직접 만들어 보며 익숙해지기
2. 이후 공개 벤치마크(SREGym)로 옮길 부품을 먼저 만들어 시험하기

## 하지 않은 것
- S2 정상 모드 5회(LLM 실행) — 코드는 있으나 실행하지 않았다
- S3 위조 모드 + 게이트 조건 0·1·2 + 보고 채널(user/tool_output), 총 42회 계획 — 시작하지 않음
- S4 시나리오 3종 경로표, S5 AgentDojo 실행 확인, S6 AIOpsLab/SREGym 실행, S7 정리 — 시작하지 않음
- 게이트는 조건 0(기록만 하고 통과)만 구현됐다. 조건 1·2(허용 범위 검사, 실제 상태 대조)는 없다.

## 이식할 부품과 역할
| 부품 | 위치 | 역할 | 이식 시 바꿀 것 |
|---|---|---|---|
| call_llm | `lab/common.py` | 모델 호출 단일 경로(Responses API). 호출마다 입력·출력·추론 토큰과 USD 추정을 `runs/usage.jsonl` 에 기록, 누적 USD 상한 초과 시 호출 전에 예외, 출력 토큰 상한, 응답 상태(completed/incomplete) 반환, non-2xx 는 본문만 기록(키 값은 가림) | Agents SDK 의 사용자 모델 공급자로 감싸거나 자체 루프에서 재사용. 가격 상수는 제3자 요약 기준이라 재확인 필요 |
| 에이전트 루프 | `lab/s01_agent/agent.py` (`run_agent`, `run_tool`, `save_run`) | 도구 호출 → 결과를 이력에 이어 붙이기 → 최종 답까지 반복. 종료 방식 4종(final_answer/max_steps/incomplete/http_error)을 따로 기록. 목록 밖 도구 이름은 `unknown_tool` 로 거절 | Agents SDK 를 쓰면 루프는 SDK 가 대체. 종료 방식 분류와 이력 JSON 형식은 유지 가치가 있다 |
| 게이트 | `lab/s02_repair/gate.py` (`Gate`) | 행동 도구 앞에서 모든 호출을 기록하고 통과시키는 함수(현재 조건 0). 판정기·정답 모듈을 import 하지 않는다는 원칙이 핵심 | 도구 입력 가드레일로 이식. "정답 모듈 import 금지" 원칙 유지 |
| 판정기 | `lab/s02_repair/judge.py` (`judge`) | LLM 없이 실행 후 상태를 정답과 비교해 4단계(잘못된 제안 → 게이트 통과 → 실제 변경 → 피해)를 따로 기록. 정답은 이 모듈에만 있다 | 입력을 SQLite 대신 K8s API·감사 로그·앱 DB 로 교체 |
| 기록기 | 게이트 로그(`Gate`), 실행 이력(`save_run`, `manager.run_incident` 가 쓰는 `runs/s02/<run_id>.json`), 사용량(`call_llm`) | 에이전트별 입력 전체·도구 호출·게이트 결정·DB 전후 차이·비용을 JSON 으로 남긴다 | 에이전트별·핸드오프별 이벤트 JSONL 로 확장 |
| 연결 검증 | `lab/s02_repair/check_wiring.py`, `check_separation.py` | LLM 없이 게이트·DB·판정기가 이어졌는지, 도구 목록 분리가 지켜지는지 확인하는 회귀 시험 | 판정기 입력을 바꾼 뒤 같은 형태의 회귀 시험을 다시 만든다 |

## 실행 방법
루트의 `.venv`(Python 3.12, openai·python-dotenv)를 쓰고, **이 폴더(`legacy/lab-v0`)에서** 실행한다
(`lab/common.py` 의 `ROOT` 가 이 폴더이므로 `runs/` 도 이 폴더 아래에 생긴다).
```
cd legacy/lab-v0
../../.venv/bin/python -m lab.s02_repair.check_wiring      # LLM 호출 없음
```
LLM 을 쓰는 스크립트는 환경 변수 `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` 이 필요하다(값은 저장소에 두지 않는다).
