# 진행 기록

| 단계 | 상태 | 이번 기록에서 한 일 / 하지 않은 일 |
| --- | --- | --- |
| Phase 0 환경 조사 | 완료 | 루트 Git·원본 pin·Python·LLM 설정 접근 방식·소스 호출 관계·기존 trace를 읽고 문서화. 새 API/Tool/VM 실행 없음 |
| Phase 1 새 Use Case 준비 | 대기 | Mock Tool·Adapter·테스트 미작성 |
| Phase 2 수동 정책 Allow/Deny | 대기 | 새 정책·Tool Call·Backend 상태 실험 없음 |
| Phase 3 실제 LLM Agent | 대기 | 모델·호출 범위·승인 미확정. API 미호출 |
| Phase 4 시스템 수준 경계 | 선택·대기 | SSH·VM 작업 없음 |
| Phase 5 선행연구 대조 | 대기 | 실험 결과 전에는 연구 공백 판정 없음 |

Phase 0의 검증은 파일·Git·패키지 메타데이터·기존 로그의 **읽기 전용 조사**와 새 문서의 형식/링크 확인이다. 실험 테스트 통과로 보고하지 않는다. Commit/Push SHA와 원격 반영 상태는 Phase 0 종료 보고에 기록한다.
