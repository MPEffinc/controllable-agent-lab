## 주의

- `Paper A 미평가`에서 `B 해결`로 간선을 그리려면 같은 policy intent, attacker control, 효과 시점, 정상 업무, provider API 조건을 고정해야 한다. 위 체인의 서로 다른 계층을 동일 실험 성능 비교로 읽지 않는다.
- [FORGE §7.1](https://arxiv.org/html/2602.16708v4), [Authorization Revocation §3.4 A6](https://arxiv.org/html/2609.21284)의 완전 중재/manifest 전제는 실제 배포에서 별도 증명해야 한다. 그렇다는 사실만으로 모든 시스템에서 뚫리는 새로운 Gap이 성립하지 않는다.
