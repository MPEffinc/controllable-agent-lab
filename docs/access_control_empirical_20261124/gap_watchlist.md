## 2026-11-25 추가한 높은 우선 검증 질문 — H10

**권한 있는 승인자가 말한 변경을 장기 메모리가 놓치거나 잘못 적용할 때 출처 검사만으로 막히는가?** [EAL-Bench v2 §4.6/C.1–C.4](https://arxiv.org/html/2609.01836v2)의 같은 paired 비교에서 source filter는 비인가 tool 행동 23.5%→7.3%와 정상 행동 93.1%→53.2%, event memory는 23.4%→9.3%와 93.0%→68.6%를 보고한다. 원점이 권한자인데 범위/철회가 잘못 기억된 149/2772 비인가 probe도 남는다. 원저자 [공식 코드 오프라인 감사](runs/EAL_offline_20261125/result.md)는 저장 자료 200개 해시를 검증했지만 raw trial은 없어 행동을 재현하지 못했다.

**강한 반박:** 같은 논문에서 3-block history 재구축은 비인가 행동 4.9%/정상 95.2%까지 개선(입력 토큰 1.2–3배). [PLACE](https://arxiv.org/html/2610.25179)의 trusted event/readback, [AuthMem-Bench](https://arxiv.org/html/2608.01679)의 source-role label, [MAP-Graph](https://arxiv.org/html/2608.10509)의 명시 철회, [Revoked but Still Authoritative](https://arxiv.org/html/2609.08258)의 현재성 guard도 조건별 해결책이다. **출처 검사만으로 충분하다는 가설은 기각**, EAL 측정 범위의 잔여 `GAP_SUPPORTED`, 독립 신규 Need `UNVERIFIED`. 같은 36 case에 기존 대안의 자연어 이벤트 추출·현재성 확인·정상 성공·비용을 함께 시험해 재구축 대조를 넘으면 새로운 방법 필요 가설을 기각한다. [강한 최신 원문 반박](h13_hard_counter_20261125.md)은 WTB v4, Epistemic Guard, MAP-Graph, PLACE, Audience-Bound, PACMI를 같은 신뢰 조건으로 대조한다. **“메모리→효과 기존 방법이 없다”는 주장 `REJECTED_HYPOTHESIS`**. 자동 event/계보 오류의 발생률·정상 손실·강한 조합 동시 실패는 `WATCH/UNVERIFIED`; 같은 입력의 시험 없이 독립 Need로 판정하지 않는다.

## 이번에 우선 기각한 넓은 주장

- **새 capability를 얻으면 통제 방법이 없다:** [AcquireBound §§3–5, 7](https://arxiv.org/html/2609.14744)이 인증된 반환 증거·quarantine·activation·effect permit을 직접 다룬다. 등록 profile/완전 중재 밖의 특정 provider만 새 질문이다.
- **도구 호출을 승인하면 provider 최종 효과도 승인된다:** [EffectBound §V/Table III](https://arxiv.org/html/2609.02866)의 native SHA 대조와 [CTA/CommitGate §4–6](https://arxiv.org/pdf/2607.10487v2)의 원자 sink가 강한 반박이다. 도구 시점과 commit 시점을 동일시하는 가설 자체가 잘못됐다.
- **서명된 인자 출처만 있으면 승인 의미의 진실성까지 보장된다:** [PAuth §III, §VI](https://arxiv.org/html/2603.17170)의 서버 task slice도 올바른 NL→코드 번역과 authoritative data를 신뢰한다. 서명은 출처를 보이지만 승인 목표가 적절했는지는 별도 질문이다.

각 후보의 상세 원문·가정·기각 조건은 [H1](deep_h1.md), [H2](deep_h2.md), [H3](deep_h3.md), [가설 원장](hypotheses.md), [추가 문헌 스캔](expanded_candidate_scan.md)에 둔다. 저자 숫자는 해당 논문 조건의 결과이며 이 세션의 새 재현 수치가 아니다.
